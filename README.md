## 📝 Task Details

### 01. To-Do List Application

A Python application for managing tasks through basic task-management operations.

**Features:**
- Add tasks
- View tasks
- Mark tasks as completed
- Manage task information

**Concepts:** Python fundamentals, data structures, and conditional statements.

### 02. Number Guessing Game

An interactive game in which the user tries to guess a randomly generated number.

**Features:**
- Random number generation
- Higher or lower hints
- Attempts tracking
- Conditional logic and repeated guessing

**Concepts:** Random number generation, conditions, loops, and user input.

### 03. Basic File Handling

A Python program that works with text files to demonstrate file reading, content modification, and file-related error handling.

**Features:**
- Read text from a file
- Find and replace specified words
- Save modified content
- Handle missing-file errors

**Concepts:** File Input/Output, string manipulation, and exception handling.

### 04. Basic Web Scraper

A Python application that retrieves webpage content and extracts book information from a sample website.

**Features:**
- Send HTTP requests
- Parse webpage HTML
- Extract book titles and prices
- Display extracted information in a readable format
- Handle request errors

**Concepts:** Requests, Beautiful Soup, HTML parsing, and data extraction.

### 05. Currency Converter

A Python application that converts an amount from one currency to another using exchange-rate data from an API.

**Features:**
- Accept an amount from the user
- Select source and target currency codes
- Retrieve exchange-rate information
- Calculate the converted amount
- Handle invalid amounts and API request errors
- Display the conversion result

**Concepts:** API integration, user input validation, mathematical operations, and exception handling.

### 06. Word Count Tool

A Python program that analyzes a text file and presents statistics about its content.

**Features:**
- Count words
- Count lines
- Count characters, including spaces and newline characters
- Calculate word frequencies
- Display the complete word-frequency distribution
- Display the five most common words
- Ignore punctuation when calculating word frequencies
- Handle missing files and empty-file input

**Concepts:** File Input/Output, string manipulation, `collections.Counter`, and text analysis.

## ⚙️ Getting Started

### Prerequisites

- Python 3 installed
- Git installed
- Internet connection for projects that access websites or APIs

### Clone the Repository

Open a terminal and run:

```bash
git clone https://github.com/dinushan02/saiket-python-development-internship.git
```

Navigate to the repository folder:

```bash
cd saiket-python-development-internship
```

### Install Dependencies

Install the required third-party Python packages:

```bash
python -m pip install -r requirements.txt
```

### Run a Project

Navigate to the relevant task folder and run its Python file.

For example, to run the Word Count Tool:

```bash
cd task-06-word-count-tool
python word_count.py
```

To run another task, navigate to its folder and use the corresponding Python filename.

**Note:** Some projects require internet access. The currency converter needs access to its exchange-rate API, and the web scraper needs access to its target website.
