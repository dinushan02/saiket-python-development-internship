## 📝 Task Details

### 01. To-Do List Application

A Python application that allows users to:

- Add tasks
- View tasks
- Mark tasks as completed
- Manage task information

The project uses dictionaries or classes to represent tasks.

**Concepts:**
- Basic Python Programming
- Data Structures
- Conditional Statements

---

### 02. Number Guessing Game

A Python game where the program generates a random number
and the user attempts to guess it.

The application provides higher/lower hints and keeps track
of the number of attempts.

**Concepts:**
- Basic Python Programming
- Random Number Generation
- Conditional Statements
- Loops

---

### 03. Basic File Handling

A Python program that reads information from a text file,
finds and replaces specific words, and saves the modified
content back to the file.

The project also handles file-related exceptions.

**Concepts:**
- File Input/Output
- String Manipulation
- Exception Handling

---

### 04. Basic Web Scraper

A Python web scraping project that extracts relevant information
from a website and presents the results in a readable format.

The project uses Requests and Beautiful Soup for retrieving
and parsing web content.

**Concepts:**
- Requests
- Beautiful Soup
- HTML Parsing
- Data Extraction

---

### 05. Currency Converter

A Python application that converts amounts between different
currencies using an exchange-rate API.

The application handles user input, currency selection,
conversion calculations, and invalid input scenarios.

**Concepts:**
- API Integration
- User Input Handling
- Mathematical Operations

---

### 06. Word Count Tool

A Python program that analyzes a text file and calculates:

- Number of words
- Number of lines
- Number of characters
- Word frequency
- Most frequently used words

The results are presented in a structured format.

**Concepts:**
- File Input/Output
- String Manipulation
- Data Analysis
